# GaoDe App 自动化测试验证框架

本文档描述了针对 "GaoDe" App 关键用户操作的自动化验证流程。

## 测试流程概述

本测试框架采用**“手动操作，脚本验证”**的核心模式：
1.  **手动操作**: 测试人员在安卓设备上，根据每个测试用例描述，手动执行指定的用户操作。
2.  **自动记录**: App的原生代码会捕捉这些操作，并将一条带有时间戳的JSON日志记录到其私有内部存储中。每个操作对应一个独立的JSON文件。
3.  **脚本验证**: 测试人员在PC上运行与操作对应的Python验证脚本。脚本通过`adb`读取设备上的日志文件，并检查最后一条记录是否正确，最终输出`PASS`或`FAIL`。

## 架构设计

*   **App端**:
    *   App内置一个`LogEvent`枚举来管理所有可记录的用户操作及其对应的日志文件名，确保类型安全。
    *   在App首次启动时，一个自定义的`Application`类会负责在内部存储 (`/data/data/com.example.GaoDe/files/`) 中预先创建好所有需要的空JSON日志文件。
    *   一个全局的`MainActivity.recordLog(...)`函数负责将日志追加写入到指定的文件中。
*   **测试端**:
    *   每个测试用例对应一个独立的Python脚本（`eval_X.py`）。
    *   脚本使用`adb exec-out run-as com.example.GaoDe cat ...`命令安全地读取App的私有文件内容到内存中进行验证，不在本地产生临时文件。

## 如何执行测试

### **前提条件**
1.  确保安卓设备已通过USB连接到PC，并已成功开启**USB调试**模式。
2.  确保`adb`环境已配置正确，可以在终端中直接运行`adb devices`并看到设备。
3.  在PC上，进入包含所有Python脚本的`Autotest`文件夹。

### **文件说明**

*   **`eval_X.py`**: 位于PC的`Autotest`文件夹下。每个脚本对应一个测试用例，负责读取设备日志并进行验证。
